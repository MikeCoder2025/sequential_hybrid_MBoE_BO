This repository contains five files, four (4) of the files are python code in the following order: (1) BO; (ii) GOOED; (iii) MBDoE and (iv) Sequential_Hybrid_MBDoE_BO
Each of the codes does three runs. A single run means from the begining to the end of the file, the three runs is done to calculate the computational time, and compare with each other methods
To run the code, clone this repository, and on your terminal you can call either of the following:
Python BO_Standlalone_3Run_MeanRuntime or 
Python MBDoE_Standlalone_3Run_MeanRuntime
Python GOOED_Standlalone_3Run_MeanRuntime
Python Sequential_Hybrid_MBDoEBO_EI_Standlalone_3Run_MeanRuntime
